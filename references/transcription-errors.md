# 录音转写错误对照表

语音转写常有识别错误。复盘提取原话时，先查本表还原真意，避免把错误转写当原话写进复盘。

本表随面试场次累积——遇到新的转写错误就补进来。

---

## 常见转写错误模式（通用）

| 错误模式 | 说明 | 示例 |
|---------|------|------|
| 同音词替换 | 转写引擎选了同音但错误的词 | 公司名、术语常被同音字替换（如某AI公司名被转成同音的普通词） |
| 英文术语音译 | 英文词被转成中文或错误英文 | SQL 被转成"circle"、Agent 被转成"engine/恩情" |
| 工具名错乱 | AI 工具名互相混淆 | Claude / Cursor / Codex / 各家模型名经常被转错 |
| 专有名词拆散 | 名词被拆成奇怪的字组合 | "截图"被转成"詹姆纳"这类不可读文本 |
| 内部工具名 | 公司内部系统被音译 | 内部工具名几乎必错，结合上下文还原 |
| 概念口误 | 面试官说专业概念时的口误/转写乱码 | 如"达摩克利斯之剑"被转成不可识别文本——往已知概念靠 |

## ⚠️ 还原原则

1. **结合上下文还原**：转写错误不孤立看，放回句子上下文判断真意。
2. **不确定的先查或问**：涉及专有名词/工具名时，联网查证或问候选人，**不要凭空猜**。
3. **保留原话实质**：清理口吃重复词（"我我我""呃"），但保留全部实质内容，绝不概括缩写。
4. **只在 q/a 字段还原**：原话字段还原成正确词，eval/better/gain 里直接用正确词。
