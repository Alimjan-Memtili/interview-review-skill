# interview-review · 面试复盘 Skill

**简体中文 | [English](README.en.md)**

把一场面试的录音转写，分析成一份**逐题对照、可累积**的 Word 复盘文档。

核心价值不在记录，而在「改进版回答」和「提升点」——把每道没答好的题重写成下次能直接背的版本。

## 它解决什么问题

面试完录了音，转写成文字后：
- 不知道自己哪里答得好、哪里答砸了
- 同一个毛病反复犯（比如自我贬低、细节淹没总结），但没有系统追踪
- 网上的面经只有题没有"我的回答 vs 满分回答"的对照

这个 skill 把复盘流程标准化：**原话提取 → 逐题评价（✅/🟡/🔴）→ 完美版改进回答 → 可迁移的提升点**，多场面试累积成一份成长档案。

## 功能

- **逐题结构化**：每道题提取"面试官问题（原话）/ 我的回答（原话）/ AI 评价 / 改进版回答 / 提升点"
- **三档评价**：✅ 好 / 🟡 可改进 / 🔴 问题——不为好看全打 ✅，🔴 和 🟡 才是复盘价值
- **改进版是完美回答**：不是润色你的原话，而是先判断内容本身有没有错（方向/事实/知识），错了推翻重写
- **诚信红线**：改进版绝不编造你没做过的经历/技能——真话有三种讲法（编内容❌/纯自贬❌/诚信+策略✅）
- **反问环节独立处理**：你的提问和面试官的回答分开评价（问得好不好 + 回答透露了什么信号）
- **自我设伤识别**：内置 5 种自我贬低的伪装形式识别，以及"理性诚实 vs 自我设伤"的关键区分
- **多场累积**：每场一个章节追加到同一份 Word 总档案；可一键切分成单场独立文档

## 安装

把整个文件夹放到你的 AI Agent 的 skills 目录（如 `~/.zcode/skills/` 或 Claude/Codex 的对应目录）：

```
skills/
└── interview-review/               # 克隆后重命名（或直接 git clone 到此名）
    ├── SKILL.md                    # 工作流与纪律
    ├── agents/openai.yaml          # 接口定义
    ├── references/
    │   ├── methodology.md          # 评价标准/答题框架/改进版规范（核心）
    │   ├── session-schema.md       # 数据结构规范
    │   └── transcription-errors.md # 转写错误对照表（随场次累积）
    └── scripts/
        ├── gen_review.py           # Word 文档生成器（python-docx）
        └── split_sessions.py       # 总档案按场次切分单场文档
```

依赖：`pip install python-docx`

## 使用

面试结束后，把录音转写文本发给你的 Agent，说"帮我复盘这场面试"。

**首场**（生成总档案）：
```bash
python scripts/gen_review.py --session session.json --out 复盘档案.docx
```

**追加**（后续每场）：
```bash
python scripts/gen_review.py --session session.json --out 复盘档案.docx --append
```

**切分单场**（每场一个独立小文档，翻阅快）：
```bash
python scripts/split_sessions.py --in 复盘档案.docx --outdir 单场文档/
```

session.json 的字段规范见 `references/session-schema.md`。

## 产出样式

每道题一个表格：

| 字段 | 内容 |
|------|------|
| 面试官问题 | 录音原话（清理口吃，不概括） |
| 我的回答（原话） | 录音原话（保留全部实质内容） |
| AI 评价 | ✅/🟡/🔴 三档 + 具体点评 |
| 改进版回答 | 先判断内容对错，再重写的完美版，可直接背 |
| 提升点 | 可迁移的表达技巧，不是空泛的"更好了" |

反问环节单独成段：你的提问被评价（问得好不好），面试官的回答被分析（透露了什么信号）。

## 复盘方法论速览

详细的评价标准见 `references/methodology.md`，几个核心原则：

1. **原话不缩写**——评价和改进才有锚点
2. **改进版用「总-分-果」**——一句话总结 → 关键动作 → 结果
3. **先判断内容对错再重写**——润色一个方向就错了的回答毫无意义
4. **诚信优先**——不能编内容，表达策略只在真话范围内做选择
5. **区分理性诚实与自我贬低**——基于客观限制说"没法做"且补证据=加分；无端否定自己=减分
